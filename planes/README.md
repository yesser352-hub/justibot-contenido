# Planes mensuales

`planes/AAAA-MM.md`: el plan del mes para que JustiBot crezca entre abogados. Lo escribe el analista el último día
del mes anterior y Carol lo aprueba en el Centro de mando.

Estructura:
1. Meta del mes (con número) y cómo se mide.
2. Tema del mes y fechas clave del calendario judicial (verificadas en fuente oficial).
3. Calendario por semana: videos del robot (2/semana), series, carruseles, historias, Shorts.
4. Acciones de crecimiento fuera del feed (SEO, WhatsApp, creadores) alineadas con el plan SEO de 90 días.
5. Qué se mide al final y qué decide Carol.
